# مسار الأمن السيبراني

منصة عربية لإدارة الدروس والتمارين والمراجعات، مع مساحة شخصية لكل حساب ChatGPT.

[فتح الموقع](https://ibeto-cyberpath.humorousdrum4.chatgpt.site)

## البناء

شغّل `node build.mjs` من جذر المستودع. ينتج ملف Worker في `dist/server/index.js`.

تستخدم النسخة المنشورة بوابة الهوية الموثوقة في OpenAI Sites وقاعدة D1 مربوطة باسم DB. مخطط القاعدة في مجلد drizzle. عند النشر خارج Sites يجب إعداد مصادقة من جهة الخادم، ومنع الوصول المباشر إلى الترويسات التي تحدد هوية المستخدم.
